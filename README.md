# DSA Journey 

This repository is a record of my journey in Data Structures and Algorithms using C++.

Whenever I solve a problem on **LeetCode, GeeksforGeeks, or Codeforces**, I add my solution here. This repository is not just about collecting solutions — it is about showing up consistently, learning from mistakes, improving my problem-solving skills, and tracking how far I have come.

## Why This Repository?

I created this repository to document my consistency in problem-solving.

Every commit represents a problem attempted, a concept learned, or progress made along the way. Some problems are easy, some are challenging, and some take multiple attempts — but each one is an opportunity to learn something new.

My goal is not just to solve more problems, but to become better at understanding them, approaching them logically, and writing efficient solutions.
